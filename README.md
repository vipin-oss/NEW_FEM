# NEW_FEM — FEM-6 reference implementation

Independent, from-the-equations implementation of the **FEM-6** model
(fractional-memory piezoelectric strain-gradient plate on the FEM-1 BFS C1
element), used to audit the delivered MATLAB code and blueprint.

The Python code is authoritative; the MATLAB file is a mirror for delivery.

## Model in one screen

Mechanical dofs per node (C1 Hermite): `u, u_x, u_y, u_xy, v, v_x, v_y, v_xy`.
Potential dofs per node: `φ, φ_x, φ_y, φ_xy`. Eight mechanical and four
potential dofs per node, 12 total.

```
[ K_uu + K_g   K_up ] [ q ]   [ f ]
[ K_upᵀ        A    ] [ φ ] = [ 0 ]        K_g = ½ ∫ M_mn B_,mᵀ C B_,n
```

with `M = ⟨ξξ⟩` the second-moment tensor of the averaging window
(cuboid `diag(a_x²/3, a_y²/3)`, 3-D ellipsoid `diag(l²/5, l²/5)` — the latter
reproduces FEM-1's `l²/10`). Condensing `φ` on the electrode gives
`K_eff = K_uu + K_up A⁻¹ K_upᵀ` and

```
k_eff² = (ω_open² − ω_short²) / ω_open² .
```

Memory: `M q̈ + K_eff [ q + τ^α D^α q ] = f`, Caputo `D^α` discretised by L1
with `b_k = (k+1)^{1-α} − k^{1-α}`, `b_0 = 1`, and Newmark (β=¼, γ=½) with the
memory term implicit.

## Status

Verification: all seven cases pass and the FEM-1 benchmark is reproduced
(4.2339 µm vs 4.23 µm published, at `l/L = 0.2` on a 20x4 mesh).

Delivered-code audit, revised: the L1 memory stencil of the delivered
`modal_fractional` reproduces the analytic transfer function to 0.52 % worst
case over `alpha = 1.0..0.3` x `Omega/w0 = 0.25..2`, and its explicit stability
bound sits just beyond the documented `gamma > 1.5` warning, so **both stand as
delivered** (an earlier finding to the contrary was my own mis-transcription
and is withdrawn; see `docs/FEM6_A1_clarification.md`). Open items: the
demonstration configuration cannot produce an electrode voltage
(`k_eff^2 = 2e-10`, physics not a bug) and the material set is a placeholder.

`matlab/` is frozen and unverified - Python is authoritative. MATLAB is not
available in this environment, so the mirror has never been executed.

## Round 12: submission polish

The manuscript in `Paper_12/` is the deliverable; `main.tex` is not compiled in
this environment (no TeX), and the structural check reports what a compiler
would have flagged.

- Figures: 14 single-panel figures became 10 in the main text and 1 in
  Appendix B. Window orientation (polar sections + maps) is one figure, the
  complex pole and the damping map are one, the two window-size panels are one,
  and the thickness figure gained the ratio of the two couplings.
- The polar sections are computed on 0–90 deg at 5 deg and mirrored over the

  is **verified** at 15 deg intervals (`paper_figures_data.json`, worst relative

  generated by `python/make_appendix_tables.py` and checked with the rest of the
  suite. The Data availability statement points at it.
- Claims: the abstract and the conclusion no longer say that a flexoelectric
  device outperforms a piezoelectric one. The extensional piezoelectric coupling
  is 0.5581, the flexoelectric bending coupling 4.2e-3 at 1 um, and the text
  says so, states that the two configurations are not additive, and states that
  mu and rho are assumed.
- `Paper_12/Highlights.tex` is a separate five-bullet file.
- `python/sync_to_overleaf.py` copies `Paper_12/` into the Overleaf-linked
  repository (`vipin-oss/Paper_12-new-`), preserving the author block, the

  push is refused (403) because this sandbox has no write access to that

## Round 14 — worked calculation, appendix references, length

- The 14 `Appendix~\ref{app:...}` sites were the cause of the double word: this
  class prints the appendix name inside `\thesection`, so `\ref` already yields
  "Appendix A" and the literal word in front of it printed it twice. The literal
  was removed at all 14 sites and no bare "Appendix" remains in the sources.
- New Sec. 6.3, "Worked calculation of the headline numbers": the window
  moments, the plane-stress reduction, the closed form against the assembled
  route, the flexoelectric smallness parameter with the finite element series
  and its local slopes, the L1 weights and the damping extraction, plus a
  summary table `tab:worked`. Every value is produced by
  `python/worked_example.py` and audited by `check_paper_numbers.py`.
- Conclusion rewritten to the requested structure: one paragraph of model, six
  findings, one paragraph of use; 258 words, no figures.
- Length: `\linespread` 1.3 -> 1.0 (the class default at 10 pt), the parameter list of Sec. 6.1 no longer
  repeats Table 1, the benchmark paragraph and the mu caveat were cut, and the
  modulus table moved to Appendix C.
- `python/check_float_order.py` rebuilds the numbering from the source and
  reports the number every float will carry, where it is first cited, and
  whether the two orders agree. Both do: figures 1-10 in citation order,
  tables 1-8 in citation order.
